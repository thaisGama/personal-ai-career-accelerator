# 🧩 How It Works

The system combines:

- an LLM for planning  
- an agent for decision making  
- vector memory for long-term tracking  
- tool integrations for file generation  

The agent outputs:

- weekly plans  
- micro tasks  
- summarized insights  
- mini-project ideas  
- LinkedIn posts  

Everything is automated.
